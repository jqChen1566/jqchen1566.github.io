## 建站初衷

欢迎来到我的个人学术主页与博客！🎉

作为一名化学专业的本科生，我希望有一个地方可以：

1. **整理学习笔记** — 量子化学、化学信息学、计算化学等课程与研究内容
2. **记录科研进展** — 课题思考、文献阅读、实验与计算结果
3. **分享技术工具** — 化学计算软件的使用经验、编程技巧
4. **建立学术档案** — 为未来的学术发展留下公开记录

---

## 技术选型

本博客使用以下技术栈构建：

| 组件 | 选型 |
|------|------|
| 静态网站生成器 | [Jekyll](https://jekyllrb.com/) |
| 主题 | [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) |
| 托管 | [GitHub Pages](https://pages.github.com/) |
| 评论系统 | Giscus (基于 GitHub Discussions) |

选择 Jekyll + Chirpy 的原因很简单：**简洁、快速、专注于写作**。Chirpy 内置了中文支持、暗色/亮色模式、代码高亮和 LaTeX 数学公式渲染（`math: true`），非常适合学术技术博客。
