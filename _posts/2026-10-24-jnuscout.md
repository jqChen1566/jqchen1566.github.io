## 项目简介

**JNUScout** 是一个面向反应路径搜索的机器学习势工具，运行在开源 SCINE 引擎（Chemoton / Puffin）之内。它在每个几何结构上比较多个机器学习势的预测，用委员会分歧衡量不确定性；超过校准阈值的结构交给更高等级的量子化学方法计算。

项目把计算速度与预测可信度分开处理：探索由机器学习势完成，可信度由校准后的不确定性指标给出，参考计算由 ORCA 完成。

---

## 方法链

计算按四个级别组织：

```text
        xTB (L1)            NNP committee (L0)                ORCA (L2/L3)
  预筛几何与构象      ->   快速探索反应路径        ->   高不确定性时回退
                                                          |
                                              参考势垒、训练标签与最终验证
```

- **L1**：GFN2-xTB，通过 `xtb` 命令行执行，用于预筛；
- **L0**：机器学习势委员会，成员为 MACE-MP-0、MACE-MPA-0 与 AIMNet2-b973c；
- **L2**：ORCA r2SCAN-D4/def2-SVP，负责几何优化与频率；
- **L3**：ORCA wB97M-V/def2-TZVP，负责高等级单点。

所有计算器遵循 ASE 协议，可以脱离 SCINE 单独使用。

---

## 不确定性量化

委员会在每个几何结构上给出逐原子力分散与族内能量分散。阈值由参考集校准：取危险构型分歧的低分位数，使假阴性率在构造上受到约束。工具同时提供秩相关、期望校准误差与覆盖率统计，用于审计阈值是否仍然适用。

能量基线对齐用于跨成员的能差比较，避免不同模型参考零点不同造成的虚假分散。

---

## SCINE 集成

- 完整的 ASE 与 SCINE 计算器桥接，覆盖全部十六个 `_*_impl` 接口，支持克隆隔离与就地结果约定；
- 进程级注入补丁，在 Puffin 与 readuct 的唯一计算器解析点注入自定义计算器；
- 未声明的方法族回退到 SCINE 原始行为，不改变既有工作流。

---

## 主动学习

仓库提供一组脚本，覆盖从路径采样到模型验证的闭环：

- `build_al_trainset.py`：沿反应路径样条采样，构建带标签训练集；
- `resplit_trainset.py`：按组成分层、按反应分组的训练集划分；
- `validate_finetune.py`：在留出反应上验证微调模型的势垒；
- `calibrate_uq.py`：在采集数据上执行不确定性校准。

方法链、不确定性定义与主动学习协议的细节见仓库 `docs/method_chain.md`。

## 安装

```bash
pip install jnuscout                 # 核心：计算器与不确定性数学
pip install "jnuscout[nnp]"         # 机器学习势：torch、mace-torch、aimnet2
pip install "jnuscout[scine]"       # SCINE：chemoton、puffin、database
```

核心只依赖 `ase` 与 `numpy`。L2/L3 需要 ORCA 6.x 学术许可；L1 需要可选的 `xtb` 可执行文件；离线机器可通过环境变量指向本地模型权重。SCINE 集成还需要运行中的 MongoDB，这是 SCINE 数据库层的既有要求。

## 适用边界

v0.1 处于早期开发阶段，接口与报告格式可能变化。框架不代替用户运行反应探索，作业仍需提交到本地引擎。不确定性阈值依赖参考集，参考集不覆盖的组成与反应类型需要重新校准；误差应按体系规模报告，不能只给总体平均值。

JNUScout 由 Jianqi Chen、Zhuoran Zhang、Laiyu Zhang，香港科技大学（广州）信息枢纽的 Mingyu Chen，以及中山大学化学学院的 Ruiqian Luo 共同开发，指导教师为暨南大学李娟教授。项目受暨南大学省级大学生创新创业训练计划（S202610559049）支持。
